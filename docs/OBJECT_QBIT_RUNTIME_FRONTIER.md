# Recursive QBit at Object runtime sites (W234)

Status: VERIFIED within the finite profiles and affected roster below;
root adversary ROBUST within that scope. Baseline: clean
`2d28758be4f5dd6ef8935c1a9fb8847f36b0464f` (W233).
The objective remains CH-compatible types and MV/projections before memory or
performance work. This slice does not narrow the overall completion condition.

## Problem and factual anchor

Leaf serde already composes through static products. W233 gives prepared
Dynamic plans a QBit leaf roster and a complete occurrence census. At baseline,
Object's typed-Dynamic reader prepared the same plans but checked mark grids
and discriminator headers without invoking that census. Selected bulk decoding
is weaker than complete preflight for an early or EOF window. Object's shared
scalar child adapter separately retains its direct-QBit-only admission.

The Oct7 source `0ca8150d9b1d0886edb2e3b4ab65eebb768d0357` delegates Object typed
paths to each child serialization (`SerializationObject.cpp:196-233`) and QBit
bulk operations to its nested tuple (`SerializationQBit.cpp:421-465`). Object
typed-path construction uses the DataTypeFactory rather than a QBit blacklist
(`DataTypeObject.cpp:861-869`). Constructor acceptance is not yet a persistence
certificate. Source and native runtime are distinct pins.

## Bounded contract and exclusions

Qualify recursive, non-Variant static QBit actuals under the existing actual
roster laws at prepared Object inferred or typed Dynamic sites, and advanced
Shared Copy path values. Immediate Nullable, Variant and Dynamic actual roots
remain excluded; nested legal Nullable products are a different boundary. Object's
declared Dynamic actual-type validator used the older static leaf grammar,
which had no QBit leaf. W234 reuses W233's bounded actual-type admission,
leaf codecs and shape census; an Object adapter supplies contextual physical
names and the correct parent/document occurrence axis. Do not add a serializer
per Array/Tuple/Map/Nested combination. Do not remove Object's existing exclusion
of Variant actuals merely because the generic Dynamic owner admits some of them.

Preserve exact dimensions, strides, nominal descriptors, sparse-arm placement,
missing versus present-empty/default values, and enclosing mark coordinates.
All relevant size/selector/plane extents must be preflighted before publication
or callbacks, including empty selections and later marks. Shared scalar values
are independently framed envelopes, not synthetic ordinary plane streams.
Caller logical and transport budgets remain shared across Object siblings.

The Object census must additionally aggregate per-mark shape element/wire
totals across inferred actual arms and declared Dynamic paths. Existing
visitor-local counters cannot grant each Object sibling a fresh full allowance.
These totals are separate from consumptive decoded-value budgets: they do not
sum every mark's payload into a new operation-wide element charge. Workspace
preflight covers retained shared counter vectors plus the current visitor's
live vectors, not a sum of sequentially discarded vectors or an RSS claim.
Additive visitor seams preserve the standalone static/Dynamic allowances. The
static visitor now also preflights its aggregate shape result extent before
any positive lane read: an insufficient allowance fails before partial I/O,
without changing exact-bound success. The new shared totals responsibility has
its own class/file. An exact/tight
two-site discriminator must distinguish this rule from incidental descriptor
or transport refusal.

The Object-wide result preflight must include every typed-Dynamic header
prefix read that precedes the QBit census, including unrelated non-QBit typed
paths. A later full selector read includes that prefix again. Counting each
shape grid once is therefore insufficient: admit full shape extents plus the
separate header reads before requesting either kind of result window.

Static declared typed QBit paths remain a separate declaration/parser frontier;
stock probes may inform it but do not silently admit it. LC(QBit), aggregate
arguments, mixed JSON/Dynamic/LC/aggregate sibling owners in a newly admitted
QBit actual, inferred legacy SharedVariant borrowed envelopes, legacy fixed-union
APIs and unqualified
Compact/sparse/custom/serializer versions retain their guards. ClickHouse's
invalid immediate Variant alternatives are not missing library types.

Complete shape checks do not authenticate every unselected payload. Logical
caps are not an allocator, RSS or throughput guarantee.

## Final verification and adversary outcome

The repeated-prefix fix prepares typed-Dynamic bindings once, includes all
three prefixes in the aggregate result preflight, and reuses those bindings
for the reads. Omitting that added prefix charge reproduces the exact one-test
early-read failure; byte-exact restoration precedes the final regressions.

The same 69 affected spec files pass 430 examples in each of DEBUG and RELEASE,
with zero failures, errors or pending examples. They run as 19 serial cohorts;
the known grouped JSON Proc-alias symptom is not claimed fixed. The ten JSON
controls and four Object/JSON controls are isolated in both modes. The final
focused roster passes 18 examples. Formatting passes for 16 owned Crystal
paths, and all three repository harnesses pass host Ruby 2.6 syntax.
